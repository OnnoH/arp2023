# Rent-a-Kit

No. 1234567

## Contents

* USB-A to MicroUSB cable
* USB-C to USB-A adapter
* ESP32 WROOM-32 microcontroller
* 170 points mini breadboard (2 x5 x 17)
* HC-SR04 ultrasonic range sensor
* 5V RGB LED Ring (compatible with WS2812B 12-Bit Neopixel)

## Projects

### Proximity warning system

Based on the distance measured by the sensor the leds will light up, indicating the warning level.
